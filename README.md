## 🌍 Проблема
Современная прополка моркови ограничена двумя неэффективными путями:
1. **Ручной труд:** Требует работы пинцетом в 3 этапа. Это физически тяжело и невозможно масштабировать на большие поля.
2. **Химическая обработка:** Гербициды губят экологию и ухудшают качество почвы уже после 2-3 циклов.

Процессы прополки и окучивания остаются последними рутинными звеньями, сдерживающими рост агропроизводства.

## 🎯 Цель проекта
Создание программируемого автономного робота для автоматизации прополки и окучивания моркови, что позволяет **масштабировать производство в несколько раз** без вреда для экологии.

## 🛸 Инновация: Платформа "Шароход"
В основе передвижения лежит наша запатентованная модель. 
**Преимущества:**
* **Высокая проходимость:** Легко преодолевает неровности почвы.
* **Маневренность и управляемость:** Позволяет совершать развороты в ограниченном пространстве.
* **Экологичность:** Минимальное давление на почву по сравнению с тяжелой техникой.



## 🛠 Алгоритм работы
1. **Старт:** Робот выставляется в начальной точке грядки.
2. **Движение:** Медленное продвижение вперед с одновременной прополкой/окучиванием.
3. **Навигация по QR-кодам:** - Камера считывает QR-код в конце грядки.
   - Робот автоматически переходит на следующую полосу.
4. **Финиш:** При обнаружении финального QR-кода робот завершает цикл и останавливается.

## 💻 Технический стек
* **Зрение:** OpenCV (распознавание рядов и QR-кодов).
* **Мозги:** Python (управляющая логика).
* **Безопасность:** Подписанные GPG-коммиты.
